# One-prompt simulator demo

Replace only the total approved budget. The agent owns environment setup; the
user does not need an existing simulator Python. Technical defaults and exact
commands are in [simulator setup](simulator-setup.md) and [quickstart](quickstart.md).

## English

> Read AGENTS.md and run the public LIBERO demo; my API key is in the environment.
> Set up an isolated SDK/simulator and pass CPU renderer plus visible-window preflight before spending.
> I authorize at most **[TOTAL] microcredits in total**. Show quotes, keep their combined caps within it, and reuse `.tenon/run.json`.
> Acquire/prepare the recommended v2 data, train, verify, deploy and open a live local window; close the session afterward. Ask only for missing access/budget/host permission and report actual outcomes.

## 中文

> 阅读 AGENTS.md，运行公开 LIBERO demo；API key 已在环境变量中。
> 请负责建立隔离的 SDK/仿真环境，先通过 CPU renderer 和可见窗口检查，再花费额度。
> 我授权的**总预算上限为 [预算] microcredits**。展示报价，训练与控制会话的上限合计不得超出预算，复用 `.tenon/run.json`。
> 获取并准备推荐的 v2 数据，完成训练、核验、部署，打开本机实时窗口，结束后关闭会话。仅询问缺少的访问权限/预算/主机授权，并如实报告实际结果。
